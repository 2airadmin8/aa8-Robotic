# PDF assets

公開用PDFを保存するディレクトリです。

## 運用ルール
- メール本文から案内する公開PDFを配置する
- 個人情報や非公開資料は置かない
- 更新時は既存URLを維持するか、リダイレクトを設定する
- メールにはPDF直リンクではなく、配信ID付きの追跡ページURLを使用する
